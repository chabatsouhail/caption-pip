## Required fidelity surfaces

- Fonts and typography: passed. The existing system-font hierarchy, compact labels, weights, line heights, and antialiasing are unchanged. The X action is icon-only to follow the extension's established control language.
- Spacing and layout rhythm: passed. Header actions use a compact 4px gap; the X button is 28 x 28px; the panel retains 14px content padding and 14px corner radii. The scrollbar stays inside the clipped shell.
- Colors and visual tokens: passed. The panel, rail, top actions, loading surface, and information toast share a static liquid-glass language based on translucent tint, fixed specular gradients, inset light, and a subtle shadow. The X action uses a transparent default surface, a subtle filled hover surface, and no outline border.
- Image quality and asset fidelity: passed. No raster UI assets or placeholders were introduced. Close uses a local Tabler vector icon, consistent with every other PiP control.
- Copy and content: passed. The redundant Reset and detection sublabel are absent, Close has an explicit tooltip and `aria-label`, and existing field labels are unchanged.
- Responsiveness: passed at the normal 640 x 446 content viewport and compact 409 x 255 content viewport. The panel remains contained and scrollable at both sizes.
- Interaction: passed. Panel open/close, scrollbar movement, live field preview, X dismissal, automatic persistence, and PiP reopen restoration all work.
